Taruh file model 3D mobil format .glb di folder ini.

Nama file yang sudah disiapkan di script:
- gclass-black.glb
- bmw-silver.glb
- white-premium-sedan.glb
- porsche-silver.glb
- innova-black.glb

Default script aman tanpa file .glb karena hasModel: false.
Kalau file sudah ada, buka src/App.jsx lalu ubah hasModel mobil tersebut menjadi true.
